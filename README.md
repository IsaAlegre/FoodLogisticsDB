# Logistics Platform – Database (MySQL)

This project consists of designing and implementing a database for a logistics platform that connects users with local food establishments and businesses. 
The system allows for the management of orders, payments, delivery personnel, promotions, and customer reviews.

## 🚀 Project objective

To create a robust and scalable database that allows:
- Registering establishments, products, and categories
- Managing users, addresses, and payment methods
- Managing orders with statuses, details, and discounts
- Assigning delivery drivers and their means of transport
- Managing active promotions and history
- Recording reviews about establishments and deliveries

## 🛠️ Technologies used

- **MySQL**
- SQL (DDL, DML, and queries)
- Compatible with Workbench, phpMyAdmin, or other managers

## 📚 Project structure

✔ Complete physical model  
✔ Tables with primary and foreign keys  
✔ CHECK constraints  
✔ Additional optimized indexes  
✔ Initial data load (30+ records per table)  
✔ Advanced queries  
✔ View created from a query
